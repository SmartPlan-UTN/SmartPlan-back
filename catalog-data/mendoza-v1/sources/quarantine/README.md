# Quarantined evidence

Prices and menu texts read from mendoza.tur.ar (EMETUR campaigns "Mansa Bodega"
and "Manso Menu"). The site publishes no reuse licence and its robots.txt asks
AI crawlers to stay away, and the CC-BY-4.0 licence of the open-data portal
does not cover its editorial pages.

Decision: these files are **not** used to build the catalog. The venues remain
(each one is validated against Google), but their prices stay UNKNOWN and their
descriptions neutral, unless the owner explicitly confirms reuse and
`INCLUDE_QUARANTINED_EMETUR=1` is set for a build.
