# Codex

Codex descubre instrucciones del repositorio en
[`../AGENTS.md`](../AGENTS.md). Esta carpeta no es parte de su mecanismo de
descubrimiento automático: es un índice compatible para acceder a todo el
contexto del proyecto sin duplicarlo.

| Enlace                        | Contenido                             |
| ----------------------------- | ------------------------------------- |
| [`AGENTS.md`](AGENTS.md)      | Instrucciones comunes del repositorio |
| [`skills/`](skills/README.md) | Reglas operativas por tipo de tarea   |
| [`docs/`](docs/README.md)     | Documentación estable del proyecto    |

Los tres enlaces apuntan a las fuentes canónicas de la raíz. Para que Codex
cargue las instrucciones, iniciá la sesión desde este repositorio; no desde
`.agents/`.
